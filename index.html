Nenu Farma

Nenu Farma es una aplicación móvil diseñada para facilitar la gestión de inventario y ventas en farmacias pequeñas y medianas.

¿Qué hace la aplicación?

  • Permite registrar productos (medicamentos y artículos generales) con sus fechas de vencimiento y precios.
  • Controla el stock disponible en tiempo real, descontando automáticamente las ventas.
  • Genera copias de seguridad de la base de datos local.

Uso de los datos de Google

Para proteger la información de tu farmacia, Nenu Farma solicita permiso para acceder a tu cuenta de Google. Utilizamos este acceso únicamente para guardar y restaurar los archivos de copia de seguridad de la base de datos en tu cuenta de Google Drive (en la carpeta oculta de datos de la aplicación). No compartimos, vendemos ni accedemos a ningún otro dato personal de tu cuenta de Google.
